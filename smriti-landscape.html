honest read

What this actually tells us

  • SMRITI is mid-pack on its easy split. 68.7% oracle overall sits between Full-context (60.2%) and Zep (71.2%) — but on a far easier split, so the true full-haystack position is lower.
  • The leaders have pulled away. mem0 (94.4%) and Supermemory (95%) are ~25 pts ahead on the full haystack. Catching them is a retrieval + extraction problem, not a visualization problem.
  • SMRITI's relative strengths hold. single-session-user (94.4%) is competitive with everyone; the weak spots are multi-session (38.9%) and preference (36.7%) — exactly the categories the observation stack targets.
  • Two gaps to close before any claim: run longmemeval_S (full haystack) and LoCoMo under one fixed judge. Until then SMRITI cannot be honestly placed on this chart.
corrections needed in the repo

SMRITI's own README is out of date

  • The README cites mem0 ≈ 49% on LongMemEval — outdated. mem0's Apr-2026 algorithm reports 94.4%. The "gap to close" against mem0 has closed, not widened.
  • The README/BENCHMARKS cite "Hindsight ~91.4%" as a reference point — this appears misidentified (hindsightai.com is a content-moderation company). No memory product with that number was found in public sources.
  • Before publishing any external comparison, these two figures should be corrected or removed, and the dashboard's honesty panel updated.
